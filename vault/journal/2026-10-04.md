### Learned

- Google Cloud hierarchy: organization → folder → project. School accounts belong to the school's organization, which is why the console asked for a "parent resource."
- Firebase pricing is the same for every account; Spark has hard limits, so no surprise bills.
- A Firebase web config is public by design; Security Rules are what protect data.
