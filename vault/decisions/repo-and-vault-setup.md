# Repo and vault setup

**Context:** The semester project needs version control, a future web deployment and a place to keep notes and Claude's write-ups.

**Choice:** One public GitHub repo (`procedural-worlds`) with the Obsidian vault in `vault/`.

**Why:** Code and notes are versioned together, Git takes care of sync and backup, Claude can read and write notes directly, and the vault doubles as documentation of the process for the portfolio. A neutral repo name keeps it portfolio-friendly instead of tied to the class.
